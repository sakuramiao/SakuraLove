# 🌸 SakuraLove - 樱花泡沫科技 粘液科技附属

 当樱花飘落，泡沫升起，温柔的科技也能绽放出治愈的力量。

## ✨ 项目简介
**SakuraLove**
 不是一款追求强度的附属，而是一套「用温柔重构科技」的浪漫扩展。
我们以樱花的凋零与重生、泡沫的轻盈与易碎为灵感，设计了一整套独有的机器、能源与合成体系：
你可以用樱花花瓣驱动发电机，也能用泡沫搭建悬浮平台，在硬核的科技生存里，找到属于自己的治愈角落。

---

## 🌸 核心内容
 樱花主题能源、机器、材料与装饰方块
-
 泡沫系列流体处理、悬浮装置、防护设备
-
 双科技线联动，隐藏配方与进阶系统
-
 唯美治愈风格，适配粘液科技原版玩法

## 📦 安装方法（RSC 专用）
1. 确保服务器已安装 **Slimefun 粘液科技** + **RykenSlimefunCustomizer（RSC）**
2.
 将本附属文件放入：
   `plugins/RykenSlimefunCustomizer/addons/`
3.
 重启服务器，即可自动加载全部内容
4. 游戏内使用 `/sf guide`
 查看所有物品
